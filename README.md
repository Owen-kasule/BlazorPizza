# Blazing Pizza (W03 Assignment)

This is a small Blazor web application used for the CSE325 W03 assignment.

Run the app locally

```bash
# from the project folder
dotnet run
```

Open the app in your browser (example URL shown after `dotnet run`):

http://localhost:5282

Navigate to the pizzas page:

http://localhost:5282/pizzas
